# Roadmap

## Phase 0 — empty prototype bootstrap

Done when: the repository has the operating structure, then the first real implementation phase can bulk-import TPS Community Safety Indicators data into Markdown and build a minimal Astro page with a map and one graph.

## Phase 1 — static crime trend dashboard

Done when: a web page shows Toronto crime-rate graphs covering 10 years of data, starting with Toronto Police Service Community Safety Indicators as the primary v1 source. (v1 is Toronto-only, not GTA — see [`decisions/001-v1-scope-is-toronto-not-gta.md`](decisions/001-v1-scope-is-toronto-not-gta.md).)
